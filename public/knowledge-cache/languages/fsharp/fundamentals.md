# Fundamentals of F#

## Getting Started

F# is a language designed for f# features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install F# on your system:

- **macOS**: `brew install fsharp`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official F# website
- **Package Manager**: fsharp's package manager

Verify your installation:

```bash
fsharp --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```fsharp
print("Hello, 100X Systems!")
```

Run it:

```bash
fsharp run hello
```

### 2. Types & Variables

Understanding the type system is crucial:

- F# is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and native types specific to its domain
