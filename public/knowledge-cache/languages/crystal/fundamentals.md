# Fundamentals of Crystal

## Getting Started

Crystal is a language designed for crystal features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install Crystal on your system:

- **macOS**: `brew install crystal`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official Crystal website
- **Package Manager**: crystal's package manager

Verify your installation:

```bash
crystal --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```crystal
print("Hello, 100X Systems!")
```

Run it:

```bash
crystal run hello
```

### 2. Types & Variables

Understanding the type system is crucial:

- Crystal is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and native types specific to its domain
