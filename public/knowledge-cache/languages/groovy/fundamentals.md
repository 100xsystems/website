# Fundamentals of Groovy

## Getting Started

Groovy is a language designed for groovy features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install Groovy on your system:

- **macOS**: `brew install groovy`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official Groovy website
- **Package Manager**: groovy's package manager

Verify your installation:

```bash
groovy --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```groovy
print("Hello, 100X Systems!")
```

Run it:

```bash
groovy run hello
```

## Core Concepts

Groovy is built around several fundamental concepts:

### 1. Core Paradigm

Groovy supports a unique combination of paradigms tailored for groovy features.

### 2. Types & Variables

Understanding the type system is crucial:

- Groovy is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and native types specific to its domain

### 3. Key Language Features

Notable aspects of Groovy:

- **Groovy core concepts** — A defining feature of the language
- **Rich standard library** — Core to idiomatic Groovy
- **Strong community and ecosystem** — Enables productive development
