# Fundamentals of Swift

## Getting Started

Swift is a language designed for fast and safe, apple ecosystem, modern syntax, automatic reference counting. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install Swift on your system:

- **macOS**: `brew install swift`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official Swift website
- **Package Manager**: Swift Package Manager

Verify your installation:

```bash
swift --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```swift
print("Hello, 100X Systems!")
```

Run it:

```bash
swift hello.swift
```

## Core Concepts

Swift is built around several fundamental concepts:

### 1. Core Paradigm

Swift supports a unique combination of paradigms tailored for fast and safe, apple ecosystem, modern syntax, automatic reference counting.

### 2. Types & Variables

Understanding the type system is crucial:

- Swift is statically typed — all types are checked at compile time
- Key types include: integers, floats, strings, booleans, and native types specific to its domain

### 3. Key Language Features

Notable aspects of Swift:

- **value types vs reference types** — A defining feature of the language
- **optionals** — Core to idiomatic Swift
- **protocol-oriented programming** — Enables productive development
