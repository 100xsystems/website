# Fundamentals of Racket

## Getting Started

Racket is a language designed for racket features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install Racket on your system:

- **macOS**: `brew install racket`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official Racket website
- **Package Manager**: racket's package manager

Verify your installation:

```bash
racket --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```racket
print("Hello, 100X Systems!")
```

Run it:

```bash
racket run hello
```

## Core Concepts

Racket is built around several fundamental concepts:

### 1. Core Paradigm

Racket supports a unique combination of paradigms tailored for racket features.

### 2. Types & Variables

Understanding the type system is crucial:

- Racket is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and native types specific to its domain

### 3. Key Language Features

Notable aspects of Racket:

- **Racket core concepts** — A defining feature of the language
- **Rich standard library** — Core to idiomatic Racket
- **Strong community and ecosystem** — Enables productive development
