# Fundamentals of V

## Getting Started

V is a language designed for v features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install V on your system:

- **macOS**: `brew install v`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official V website
- **Package Manager**: v's package manager

Verify your installation:

```bash
v --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```v
print("Hello, 100X Systems!")
```

Run it:

```bash
v run hello
```

### 2. Types & Variables

Understanding the type system is crucial:

- V is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and native types specific to its domain

### 3. Key Language Features

Notable aspects of V:
