# Fundamentals of Scheme

## Getting Started

Scheme is a language designed for scheme features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install Scheme on your system:

- **macOS**: `brew install scheme`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official Scheme website
- **Package Manager**: scheme's package manager

Verify your installation:

```bash
scheme --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```scheme
print("Hello, 100X Systems!")
```

Run it:

```bash
scheme run hello
```

## Core Concepts

Scheme is built around several fundamental concepts:

### 1. Core Paradigm

Scheme supports a unique combination of paradigms tailored for scheme features.

### 2. Types & Variables

Understanding the type system is crucial:

- Scheme is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and native types specific to its domain

### 3. Key Language Features

Notable aspects of Scheme:

- **Scheme core concepts** — A defining feature of the language
- **Rich standard library** — Core to idiomatic Scheme
- **Strong community and ecosystem** — Enables productive development
