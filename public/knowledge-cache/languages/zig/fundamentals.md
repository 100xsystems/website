# Fundamentals of Zig

## Getting Started

Zig is a language designed for zig features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install Zig on your system:

- **macOS**: `brew install zig`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official Zig website
- **Package Manager**: zig's package manager

Verify your installation:

```bash
zig --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```zig
print("Hello, 100X Systems!")
```

Run it:

```bash
zig run hello
```

## Core Concepts

Zig is built around several fundamental concepts:

### 1. Core Paradigm

Zig supports systems programming with manual memory control and zero-cost abstractions.

### 2. Types & Variables

Understanding the type system is crucial:

- Zig is statically typed — all types are checked at compile time
- Key types include: integers, floats, strings, booleans, and native types specific to its domain

### 3. Key Language Features

Notable aspects of Zig:

- **Zig core concepts** — A defining feature of the language
- **Rich standard library** — Core to idiomatic Zig
- **Strong community and ecosystem** — Enables productive development
