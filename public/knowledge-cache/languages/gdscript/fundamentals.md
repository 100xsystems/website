# Fundamentals of GDScript

## Getting Started

GDScript is a language designed for gdscript features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install GDScript on your system:

- **macOS**: `brew install gdscript`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official GDScript website
- **Package Manager**: gdscript's package manager

Verify your installation:

```bash
gdscript --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```gdscript
print("Hello, 100X Systems!")
```

Run it:

```bash
gdscript run hello
```

### 2. Types & Variables

Understanding the type system is crucial:

- GDScript is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and native types specific to its domain
