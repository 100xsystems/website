# Fundamentals of D

## Getting Started

D is a language designed for d features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install D on your system:

- **macOS**: `brew install d`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official D website
- **Package Manager**: d's package manager

Verify your installation:

```bash
d --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```d
print("Hello, 100X Systems!")
```

Run it:

```bash
d run hello
```
