# Fundamentals of Bash

## Getting Started

Bash is a language designed for bash features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install Bash on your system:

- **macOS**: `brew install bash`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official Bash website
- **Package Manager**: bash's package manager

Verify your installation:

```bash
bash --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```bash
print("Hello, 100X Systems!")
```

Run it:

```bash
bash run hello
```

## Core Concepts

Bash is built around several fundamental concepts:

### 1. Core Paradigm

Bash supports a unique combination of paradigms tailored for bash features.

### 2. Types & Variables

Understanding the type system is crucial:

- Bash is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and native types specific to its domain

### 3. Key Language Features

Notable aspects of Bash:

- **Bash core concepts** — A defining feature of the language
- **Rich standard library** — Core to idiomatic Bash
- **Strong community and ecosystem** — Enables productive development
