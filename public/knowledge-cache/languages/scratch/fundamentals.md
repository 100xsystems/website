# Fundamentals of Scratch

## Getting Started

Scratch is a language designed for scratch features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install Scratch on your system:

- **macOS**: `brew install scratch`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official Scratch website
- **Package Manager**: scratch's package manager

Verify your installation:

```bash
scratch --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```scratch
print("Hello, 100X Systems!")
```

Run it:

```bash
scratch run hello
```

### 2. Types & Variables

Understanding the type system is crucial:

- Scratch is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and native types specific to its domain

Notable aspects of Scratch:
