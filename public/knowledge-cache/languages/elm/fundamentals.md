# Fundamentals of Elm

## Getting Started

Elm is a language designed for elm features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install Elm on your system:

- **macOS**: `brew install elm`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official Elm website
- **Package Manager**: elm's package manager

Verify your installation:

```bash
elm --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```elm
print("Hello, 100X Systems!")
```

Run it:

```bash
elm run hello
```

### 2. Types & Variables

Understanding the type system is crucial:

- Elm is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and native types specific to its domain
