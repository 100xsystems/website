# Fundamentals of Wolfram Language

## Getting Started

Wolfram Language is a language designed for wolfram language features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install Wolfram Language on your system:

- **macOS**: `brew install wolfram-language`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official Wolfram Language website
- **Package Manager**: wolfram-language's package manager

Verify your installation:

```bash
wolfram-language --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```wolfram-language
print("Hello, 100X Systems!")
```

Run it:

```bash
wolfram-language run hello
```
