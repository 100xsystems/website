# Fundamentals of Ada

## Getting Started

Ada is a language designed for ada features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install Ada on your system:

- **macOS**: `brew install ada`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official Ada website
- **Package Manager**: ada's package manager

Verify your installation:

```bash
ada --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```ada
print("Hello, 100X Systems!")
```

Run it:

```bash
ada run hello
```

## Core Concepts

Ada is built around several fundamental concepts:

### 1. Core Paradigm

Ada supports a unique combination of paradigms tailored for ada features.

### 2. Types & Variables

Understanding the type system is crucial:

- Ada is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and native types specific to its domain

### 3. Key Language Features

Notable aspects of Ada:

- **Ada core concepts** — A defining feature of the language
- **Rich standard library** — Core to idiomatic Ada
- **Strong community and ecosystem** — Enables productive development
