# Fundamentals of PureScript

## Getting Started

PureScript is a language designed for purescript features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install PureScript on your system:

- **macOS**: `brew install purescript`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official PureScript website
- **Package Manager**: purescript's package manager

Verify your installation:

```bash
purescript --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```purescript
print("Hello, 100X Systems!")
```

Run it:

```bash
purescript run hello
```

### 2. Types & Variables

Understanding the type system is crucial:

- PureScript is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and native types specific to its domain

### 3. Key Language Features

Notable aspects of PureScript:
