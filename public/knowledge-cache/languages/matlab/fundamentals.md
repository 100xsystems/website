# Fundamentals of MATLAB

## Getting Started

MATLAB is a tool designed for matlab features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install MATLAB on your system:

- **macOS**: `brew install matlab`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official MATLAB website
- **Package Manager**: matlab's package manager

Verify your installation:

```bash
matlab --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```matlab
print("Hello, 100X Systems!")
```

Run it:

```bash
matlab run hello
```

MATLAB is built around several fundamental concepts:

### 1. Core Paradigm

MATLAB supports a unique combination of paradigms tailored for matlab features.

### 2. Types & Variables

Understanding the type system is crucial:

- MATLAB is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and native types specific to its domain

### 3. Key Language Features

Notable aspects of MATLAB:
