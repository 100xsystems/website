# Fundamentals of COBOL

## Getting Started

COBOL is a language designed for cobol features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install COBOL on your system:

- **macOS**: `brew install cobol`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official COBOL website
- **Package Manager**: cobol's package manager

Verify your installation:

```bash
cobol --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```cobol
print("Hello, 100X Systems!")
```

Run it:

```bash
cobol run hello
```

### 2. Types & Variables

Understanding the type system is crucial:

- COBOL is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and native types specific to its domain

### 3. Key Language Features

Notable aspects of COBOL:
