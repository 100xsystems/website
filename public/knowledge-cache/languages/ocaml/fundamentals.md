# Fundamentals of OCaml

## Getting Started

OCaml is a language designed for ocaml features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install OCaml on your system:

- **macOS**: `brew install ocaml`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official OCaml website
- **Package Manager**: ocaml's package manager

Verify your installation:

```bash
ocaml --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```ocaml
print("Hello, 100X Systems!")
```

Run it:

```bash
ocaml run hello
```

## Core Concepts

OCaml is built around several fundamental concepts:

### 1. Core Paradigm

OCaml supports a unique combination of paradigms tailored for ocaml features.

### 2. Types & Variables

Understanding the type system is crucial:

- OCaml is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and algebraic data types and pattern matching

### 3. Key Language Features

Notable aspects of OCaml:

- **OCaml core concepts** — A defining feature of the language
- **Rich standard library** — Core to idiomatic OCaml
- **Strong community and ecosystem** — Enables productive development
