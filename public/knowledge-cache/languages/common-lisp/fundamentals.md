# Fundamentals of Common Lisp

## Getting Started

Common Lisp is a language designed for common lisp features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install Common Lisp on your system:

- **macOS**: `brew install common-lisp`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official Common Lisp website
- **Package Manager**: common-lisp's package manager

Verify your installation:

```bash
common-lisp --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```common-lisp
print("Hello, 100X Systems!")
```

Run it:

```bash
common-lisp run hello
```

### 2. Types & Variables

Understanding the type system is crucial:

- Common Lisp is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and native types specific to its domain

### 3. Key Language Features

Notable aspects of Common Lisp:

- **Common Lisp core concepts** — A defining feature of the language
- **Rich standard library** — Core to idiomatic Common Lisp
