# Fundamentals of Nim

## Getting Started

Nim is a language designed for nim features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install Nim on your system:

- **macOS**: `brew install nim`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official Nim website
- **Package Manager**: nim's package manager

Verify your installation:

```bash
nim --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```nim
print("Hello, 100X Systems!")
```

Run it:

```bash
nim run hello
```

## Core Concepts

Nim is built around several fundamental concepts:

### 1. Core Paradigm

Nim supports a unique combination of paradigms tailored for nim features.

### 2. Types & Variables

Understanding the type system is crucial:

- Nim is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and native types specific to its domain

### 3. Key Language Features

Notable aspects of Nim:

- **Nim core concepts** — A defining feature of the language
- **Rich standard library** — Core to idiomatic Nim
- **Strong community and ecosystem** — Enables productive development
