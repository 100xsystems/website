# Fundamentals of Assembly

## Getting Started

Assembly is a language designed for assembly features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install Assembly on your system:

- **macOS**: `brew install assembly`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official Assembly website
- **Package Manager**: assembly's package manager

Verify your installation:

```bash
assembly --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```assembly
print("Hello, 100X Systems!")
```

Run it:

```bash
assembly run hello
```

### 2. Types & Variables

Understanding the type system is crucial:
