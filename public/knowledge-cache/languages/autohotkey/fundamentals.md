# Fundamentals of AutoHotkey

## Getting Started

AutoHotkey is a language designed for autohotkey features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install AutoHotkey on your system:

- **macOS**: `brew install autohotkey`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official AutoHotkey website
- **Package Manager**: autohotkey's package manager

Verify your installation:

```bash
autohotkey --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```autohotkey
print("Hello, 100X Systems!")
```

Run it:

```bash
autohotkey run hello
```

### 2. Types & Variables

Understanding the type system is crucial:
