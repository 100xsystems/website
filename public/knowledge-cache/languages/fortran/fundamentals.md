# Fundamentals of Fortran

## Getting Started

Fortran is a language designed for fortran features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install Fortran on your system:

- **macOS**: `brew install fortran`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official Fortran website
- **Package Manager**: fortran's package manager

Verify your installation:

```bash
fortran --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```fortran
print("Hello, 100X Systems!")
```

Run it:

```bash
fortran run hello
```

## Core Concepts

Fortran is built around several fundamental concepts:

### 1. Core Paradigm

Fortran supports a unique combination of paradigms tailored for fortran features.

### 2. Types & Variables

Understanding the type system is crucial:

- Fortran is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and native types specific to its domain

### 3. Key Language Features

Notable aspects of Fortran:

- **Fortran core concepts** — A defining feature of the language
- **Rich standard library** — Core to idiomatic Fortran
- **Strong community and ecosystem** — Enables productive development
