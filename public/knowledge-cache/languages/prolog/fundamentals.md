# Fundamentals of Prolog

## Getting Started

Prolog is a language designed for prolog features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install Prolog on your system:

- **macOS**: `brew install prolog`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official Prolog website
- **Package Manager**: prolog's package manager

Verify your installation:

```bash
prolog --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```prolog
print("Hello, 100X Systems!")
```

Run it:

```bash
prolog run hello
```

## Core Concepts

Prolog is built around several fundamental concepts:

### 1. Core Paradigm

Prolog supports a unique combination of paradigms tailored for prolog features.

### 2. Types & Variables

Understanding the type system is crucial:

- Prolog is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and native types specific to its domain

### 3. Key Language Features

Notable aspects of Prolog:

- **Prolog core concepts** — A defining feature of the language
- **Rich standard library** — Core to idiomatic Prolog
- **Strong community and ecosystem** — Enables productive development
