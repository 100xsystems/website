# Fundamentals of Gleam

## Getting Started

Gleam is a language designed for gleam features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install Gleam on your system:

- **macOS**: `brew install gleam`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official Gleam website
- **Package Manager**: gleam's package manager

Verify your installation:

```bash
gleam --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```gleam
print("Hello, 100X Systems!")
```

Run it:

```bash
gleam run hello
```
