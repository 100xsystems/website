# Fundamentals of WebAssembly

## Getting Started

WebAssembly is a language designed for webassembly features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install WebAssembly on your system:

- **macOS**: `brew install webassembly`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official WebAssembly website
- **Package Manager**: webassembly's package manager

Verify your installation:

```bash
webassembly --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```webassembly
print("Hello, 100X Systems!")
```

Run it:

```bash
webassembly run hello
```

## Core Concepts

WebAssembly is built around several fundamental concepts:

### 1. Core Paradigm

WebAssembly supports a unique combination of paradigms tailored for webassembly features.

### 2. Types & Variables

Understanding the type system is crucial:

- WebAssembly is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and native types specific to its domain

### 3. Key Language Features

Notable aspects of WebAssembly:

- **WebAssembly core concepts** — A defining feature of the language
- **Rich standard library** — Core to idiomatic WebAssembly
- **Strong community and ecosystem** — Enables productive development
