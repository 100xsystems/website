# Fundamentals of Solidity

## Getting Started

Solidity is a language designed for solidity features. This lesson covers everything you need to write your first program and understand the core concepts.

### Installation & Setup

Install Solidity on your system:

- **macOS**: `brew install solidity`
- **Linux**: Use your distribution's package manager
- **Windows**: Download from the official Solidity website
- **Package Manager**: solidity's package manager

Verify your installation:

```bash
solidity --version
```

### Hello, 100X Systems!

Every journey begins with a single program:

```solidity
print("Hello, 100X Systems!")
```

Run it:

```bash
solidity run hello
```

### 2. Types & Variables

Understanding the type system is crucial:

- Solidity is progressively typed — you can add types where you need them
- Key types include: integers, floats, strings, booleans, and native types specific to its domain
